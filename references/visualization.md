# 阶段 4:可视化规范

可视化直接决定论文第一印象。满篇公式和数值会让人厌倦,工整的排版和好看且恰当的可视化是雪中送炭,能拔高论文基础档次,也让人有耐心看下去。全论文必须**统一风格**:同一套配色、同一套字体、同一种版式语言。

## 1. 配色:学术庄重、克制、语义统一

### 1.1 三套学术配色风格(全论文选一套,不混用)

配色风格决定论文气质。以下三套都低饱和、高对比、学术庄重,按题目气质选一套,全文统一:

### 1.2 语义色(全论文统一,独立于风格)

无论选哪套主色,正/负/中性三类语义色必须全局一致:

- 正/高/主 = 主色系的**蓝/绿**系第一主色
- 负/低/退化 = 主色系的**红/橙**系第一主色
- 中性/零 = 灰 `#C4C9CE`

负向条形图/棒棒糖图,横线 `#333`,数据点正蓝负橙,零值灰点——一眼可读。

### 1.3 色盲安全备选(Okabe-Ito)

若担心色觉障碍评审,可用 Okabe-Ito 色盲安全调色板:

**克制原则(所有风格通用)**:

## 2. 绘图类型选择指南(核心:合适恰当,不为炫技而炫技)

按可视化任务类型选图。**基础图优先,进阶图只在基础图确实表达不清时才用**。频繁堆砌高级图表是减分项。

### 2.1 对比型(Comparison)——比较不同类别/组间的数值差异

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 柱状图/条形图 | 少量类别(≤10)的绝对值对比;类别名长用横向条形 |
| 基础 | 分组柱状图 | 两个分类维度下的交叉对比 |
| 进阶 | 堆积柱状图 | 既要对比总量,又要看内部构成比例 |
| 进阶 | 100% 堆积柱状图 | 重点在比例构成的组间对比,而非绝对值 |
| 进阶 | 雷达图 ❌不绘制 | 多维对比改用分组柱状图/平行坐标表达;雷达图 AI 同质化最严重、难读难看,**本 skill 规定不绘制**(见 2.9) |
| 进阶 | 哑铃图(Dumbbell) | 强调两组数据点之间的差距 |
| 进阶 | 子弹图(Bullet) | 单一指标与目标值/基准值的紧凑对比 |
| 进阶 | 南丁格尔玫瑰图 | 扇形面积/半径显示占比,可堆叠 |

### 2.2 时序型(Change over Time)——展示数据随时间演变

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 折线图 | 最经典时序趋势,1–5 条序列 |
| 基础 | 面积图 | 强调累积量/总量随时间变化 |
| 基础 | 柱状图 | 离散时间点(月度、季度)的数值对比 |
| 进阶 | 堆积面积图 | 各部分对总量的贡献随时间变化 |
| 进阶 | 阶梯图 | 状态保持型数据(股票价格、开关状态) |
| 进阶 | 迷你图(Sparkline) | 表格单元格内展示大量序列微观趋势 |
| 进阶 | 热力图(时序矩阵) | 超长时序的周期模式识别(多年月度数据),**确实合适时绘制**,不滥用(见 2.9) |
| 进阶 | 雷达图(极坐标) ❌不绘制 | 时间映射圆周比同期,改用折线图(每年一条)或分组柱状图;雷达图本 skill 不绘制(见 2.9) |
| 进阶 | 瀑布图 | 连续时间点上增量/减量的累积效应 |

### 2.3 凸显变动/偏差型——强调相对基准(零/均值/目标)的偏离

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 带参考线的柱状图 | 与单一目标值对比,正负偏离一目了然 |
| 基础 | 折线图 + 均值线 | 展示序列围绕均值的波动 |
| 进阶 | 斜率图(Slope) | 两个时间点之间多项目的变化方向与幅度 |
| 进阶 | 发散型条形图(Diverging Bar) | 以零为中心,展示正负情感、盈亏 |
| 进阶 | 盈余/赤字填充折线图 | 气候、财务数据中高/低于基线的区域着色 |
| 进阶 | 瀑布图 | 逐项拆解从起点到终点的增减变动 |
| 进阶 | 哑铃图/箭头图 | 强调起点到终点的变化量 |

### 2.4 构成/部分-整体型——展示整体中各部分占比

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 饼图/环形图 | 简单构成,类别少(≤5),需直观占比感 |
| 基础 | 堆积柱状图 | 多组之间的构成对比 |
| 基础 | 堆积面积图 | 构成比例随时间的演变 |
| 进阶 | 树状图(Treemap) | 层级结构的多层占比 |
| 进阶 | 旭日图(Sunburst) | 多层嵌套构成的层级展开 |
| 进阶 | 马赛克图(Mosaic) | 两个分类变量交叉下的比例构成 |
| 进阶 | 华夫饼图(Waffle) | 100 格整的百分比展示,比饼图精确 |

### 2.5 分布型(数据驱动型题目常用,放论文开头数据预处理节)

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 直方图 | 单变量数值分布,观察峰态、偏态 |
| 基础 | 箱线图(Box Plot) | 多组分布的统计摘要(中位数、四分位距、异常值) |
| 进阶 | 小提琴图(Violin) | 同时展示分布密度与箱线统计量 |
| 进阶 | 蜂群图(Beeswarm) | 强调每个个体数据点分布,避免重叠 |
| 进阶 | 密度图(KDE) | 平滑展示连续变量概率分布 |
| 进阶 | 2D 直方图/热力图 | 两个数值变量的联合分布密度 |
| 进阶 | 累积分布图(CDF) | 展示小于某值的概率,适合对比不同组 |

### 2.6 关系型——探索变量间相关性、聚类、异常

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 散点图 | 两个数值变量的相关关系(线性/非线性) |
| 基础 | 气泡图 | 散点图 + 第三维度(点大小编码数值) |
| 进阶 | 热力图(相关矩阵) | 多变量间的相关系数矩阵(见 2.9,确实合适时绘制) |
| 进阶 | 平行坐标图 | 高维数据的模式识别与聚类 |
| 进阶 | 散点图矩阵(Pair Plot) | 多变量两两关系的批量展示 |
| 进阶 | 网络图/力导向图 | 节点-边关系(社交网络、知识图谱) |

### 2.7 地理空间型——数据在地理空间上的分布/模式

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 符号地图(Bubble Map) | 地理点以气泡大小表示数值 |
| 基础 | 等值区域图(Choropleth) | 行政区划填充颜色表示比率/密度 |
| 进阶 | 热力地图(Hexbin/Grid) | 连续空间上的密度分布 |

| 进阶 | 流向地图(Flow Map) | 起点到终点的流量/迁移路径 |
| 进阶 | 变形地图(Cartogram) | 以区域面积编码数值,牺牲地理保真度 |

### 2.8 流程/转化型——资源、用户、能量等在状态/节点间的流动与转化

| 层级 | 图表 | 适用场景 |
|---|---|---|
| 基础 | 漏斗图 | 线性流程的逐层转化与流失 |
| 进阶 | 桑基图(Sankey) | 多源多汇的流量分配(能量流、资金流向) |
| 进阶 | 弦图(Chord) | 双向流量关系(城市间人口迁移) |
| 进阶 | 甘特图(Gantt) | 项目进度与任务依赖的时间线(工业流程/调度/时段分配常用) |

### 2.9 避免可视化同质化(重要提醒)

AI 泛滥导致可视化同质化,最典型的是**雷达图**,其次是被滥用的**热力图**。本 skill 的规定:

- **雷达图:不绘制。** 雷达图 AI 同质化最严重、辨识度低、多维数值难读、画不好又难看;任何"多维对比"需求都改用**分组柱状图 / 条形图 / 平行坐标图 / 小倍数图(facet)** 表达。
- **热力图:确实合适时才绘制,不滥用。** 热力图在这些场景是合适甚至最佳的:相关矩阵(多变量相关系数,见 §2.6)、联合分布密度(§2.6 的 2D 直方图/热力图)、时序周期矩阵(§2.2)、空间密度/等值线(§2.7)。若用柱状/折线/散点能一样说清,优先它们;不要为了"看起来高级"而堆热力图。
- 不为炫技而炫技:频繁使用高级图表或堆砌图表都是减分项。
- 绘图不死板:可通过子图、放大缩小、映射关系灵活组图。例如在热力图四周或对称位置,选其一绘制数据组的散点图、直方图,既展现总体关系又展现个体分布。

## 3. 字体:中文宋体、英文数字 Times 风格,全论文统一

### 3.1 原则
正文图表一律:中文用**宋体**(serif 衬线),英文与数字用 **Times 风格**衬线。全论文(正文 + 图 + 表)同一字体语言。

### 3.2 matplotlib 配方(已验证,matplotlib ≥ 3.6)
关键:用 `font.family` **列表**,matplotlib 会按字形在多字体间回退——西文落入 Times 兼容字体,中文落入宋体:

```python
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
matplotlib.rcParams['font.family'] = ['Liberation Serif', 'Noto Serif CJK SC']
matplotlib.rcParams['axes.unicode_minus'] = False   # 负号否则变方块
```

- `Liberation Serif` 是 Times New Roman 的度量兼容替代(本机无 Times 时用);有 Times New Roman 则放最前。
- `Noto Serif CJK SC` 是中文宋体;若环境用黑体风格,才替换为 `Noto Sans CJK SC`。
- **不要**只写 `font.family='serif'` 再靠 `font.serif` 列表——那只取第一个字体,中文会缺字形。
- 字体大小层级:标题 11、轴标签 10、刻度 8-10、数值标注 8-9。**子图一行排列时,把图的字体单独调大,免得看不清。**

### 3.3 LaTeX 配方
- 正文中文宋体:xelatex + `ctexart`/`cumcmthesis`(fontset 默认 FandolSong/SimSun)。
- 西文/数学 Times 风格:加 `\usepackage{newtxtext,newtxmath}`(或 `\usepackage{mathptmx}`),需实测与 ctex 兼容;编译异常则保留 LaTeX 默认衬线,**全文字体一致优先于"必须 Times"**。

## 4. 版式:去噪、直接、留白

- 去上/右边框:`ax.spines['top'].set_visible(False); ax.spines['right'].set_visible(False)`。
- 网格极浅:仅主方向 `ax.grid(axis='x', alpha=0.25, lw=0.5)`,`ax.set_axisbelow(True)`。
- **直接标注数值**:条形/棒棒糖每根标注具体数字(`ax.text(v+0.001, i, '%.3f'%v, ...)`),**少用图例,能直接标注就直接标注**——图例是最后手段。
- 零线醒目:`ax.axvline(0, color='#333', lw=1.1)`(水平条形)或 `axhline`(垂直条形)。
- 条形高度 `height=0.6`(barh)、宽度 `0.62`(bar),比默认细,更精致。
- 每张图 `plt.tight_layout()`,图内四周留白,标题不贴边。

## 5. TikZ:架构图、流程图与物理/机制示意图

**流程图、机理图、物理示意图一律用 TikZ 矢量绘制**(不糊、可随页缩放、风格与正文一致),matplotlib 只画数据图。

### 5.0 两类结构图的分工(先分清再动手画)

数模论文里的结构图分两类,**画法不同、位置不同、数量不同,不可混用**:

| 图 | 数量 | 位置 | 画法 |
|---|---|---|---|
| **论文总体架构图** | 全文 **1 张** | **问题分析节末尾** | 用捆绑子 skill `skills/tikz-architecture-diagram`(分层架构:层带 + 层标块 + 组件盒 + 层间数据流箭头) |
| **各问求解流程图** | **每问 1 张** | 各问"模型建立与求解"开头 | 用下面 5.1 的**蛇形(横向)TikZ 流程图模板**(snake layout,整体横向展开,见 §5.1.1) |

判据很简单:**表达"全文如何分层组织、各问如何归位"的是架构图;表达"这一问从输入到输出怎么一步步算"的是流程图。**

- 总体架构图承载论文骨架,让评委读正文前先看懂全局。典型五层:数据与题面层 → 模型构建层 → 算法求解层 → 结果输出层 → 结论与推广层。绘制方法、坐标配方、配色、质量门禁全部见 `skills/tikz-architecture-diagram/SKILL.md`,模板 `templates/fig.tex` 改标签即用,`templates/build.sh` 一键出 PDF/PNG/SVG,`scripts/check_overlap.py` 核验文字零重叠。产出 PDF 后用 `\includegraphics[width=0.95\textwidth]` 矢量嵌入。
- **不要**用分层架构的形式去画小问流程图,也**不要**把架构图复制成多张充当各问流程图——评委一眼能看出是同一张图换标签。
- **不要**用 matplotlib 画这两类图。

### 5.1 基础模板(全论文风格统一)

```latex
\usepackage{tikz}
\usetikzlibrary{arrows.meta, positioning, shapes.geometric}

\begin{figure}[H]          % 就近固定,避免漂走
  \centering
  \resizebox{0.92\textwidth}{!}{   % 控宽!高度随比例缩放
  \begin{tikzpicture}[
      box/.style={draw, rounded corners=2pt, align=center,
                  minimum height=0.7cm, text width=2.9cm, font=\footnotesize,
                  fill=gray!8, draw=gray!55},
      dat/.style={draw, rounded corners=2pt, align=center,
                  minimum height=0.7cm, text width=2.9cm, font=\footnotesize,
                  fill=blue!7, draw=blue!50},
      res/.style={draw, rounded corners=2pt, align=center,
                  minimum height=0.7cm, text width=3.2cm, font=\footnotesize,
                  fill=green!7, draw=green!55!black},
      arrow/.style={-{Stealth[length=2mm]}, thick, gray!70}]
    \node[dat] (d1) {数据/输入};
    \node[box, below=0.55cm of d1] (d2) {处理步骤};
    \node[box, below=0.55cm of d2] (d3) {决策};
    \node[res, below=0.55cm of d3] (d4) {结果};
    \draw[arrow] (d1)--(d2) (d2)--(d3) (d3)--(d4);
  \end{tikzpicture}}
  \caption{问题二: 求解流程。流程自上而下分四步:先由附件 2 读入各场馆容量
  与场次安排作为输入数据,经缺失值填补与单位统一后形成决策变量的可行域;再以
  总旅行负担最小为目标建立整数规划模型,约束包含容量上限、休息间隔与配额三类;
  随后用分支定界求解并以贪心解作为上界加速,迭代 412 次后收敛;最终输出完整

```

注意 caption 用 **100–150 字**长说明(逐步交代输入、处理、输出与关键数值),不写"图2 求解流程"这种光秃标题;`[H]` 强制就地固定防漂移。详见 `writing.md` 第 6.1–6.2 节。

> 上面的纵向模板**仅当节点 ≤3 时作回退**;各问流程图(**每问 1 张**)的标准画法是下面的 **§5.1.1 蛇形(横向)布局**。

#### 5.1.1 各问流程图标准画法:蛇形(横向)布局 + 现代柔和配色

**布局规则(硬性)**:整体呈**横向展开**的蛇形 / 波浪流,**绝不是"糖葫芦"式一条直线**:
- **蛇形换行**:第 1 行 **左→右**,第 2 行从右端 **折返 右→左**,第 3 行(若有)再 **左→右**,如此往复——像波浪一样自然弯曲。
- 每行列数按节点数均分(通常 3 个/行),行末用**竖直向下的短箭头**转行,箭头始终连续不断。
- 整体 **宽 > 高**(与 §6 原则一致),不出现"图比页面还高"。

**现代柔和配色(硬性,6 色,柔和不刺眼)**:沿蛇形节点顺序**循环取色**,节点填色用浅填、描边用同色加深、文字统一近黑保证可读。

| 颜色 | 取色顺序(步骤 1/7…) | RGB(柔和) | 浅填 / 描边 |
|---|---|---|---|
| 珊瑚红 | 步骤 1、7… | (244,151,142) | `coral!18` / `coral!60!black` |
| 青绿 | 步骤 2、8… | (77,182,172) | `teal!18` / `teal!60!black` |
| 天蓝 | 步骤 3、9… | (100,181,246) | `sky!18` / `sky!60!black` |
| 薄荷绿 | 步骤 4 | (152,216,200) | `mint!18` / `mint!60!black` |
| 暖黄 | 步骤 5 | (255,213,158) | `warm!18` / `warm!60!black` |
| 淡紫 | 步骤 6 | (197,176,230) | `lilac!18` / `lilac!60!black` |

**蛇形 TikZ 模板**(复制 `tikzpicture` 块到论文对应 `\begin{figure}[H]` 内,改节点文字即可;完整可编译示例见 `templates/flow_snake.tex`):

### 5.2 长宽比控制(重点)
- 用 `\resizebox{0.92\textwidth}{!}` 控宽,**高度自动按比例**——最稳的长宽比控制手段。
- **蛇形(横向)流程为各问流程图默认**:3 节点/行,整体宽 > 高,节点 `minimum width=2.7cm`、`minimum height=0.85cm`,行距 `yshift=-2cm`,不出现"图比页面还高"。节点 ≤3 时才回退到下面的纵向直排。
- 纵向流程(回退):方框 `text width=2.9~3.3cm`、`minimum height=0.7cm`,垂直间距 `below=0.55cm of`(太紧则 0.7cm)。图不应比页面还高。
- 横向流程/多分支:`text width` 小些(2.6cm)或 `\resizebox{0.88\textwidth}{!}`,保证整图不超版心。
- **过高的信号**:整页被一张流程图占满、或图高 > 图宽。此时缩短文字、合并节点、改两行排布。

### 5.3 节点样式语义
- **蛇形流程图节点**用 §5.1.1 的现代柔和 6 色(`coral`/`teal`/`sky`/`mint`/`warm`/`lilac`),沿蛇形顺序循环取色,填色浅(`!18`)、描边同色加深(`!60!black`)、文字近黑(`black!82`)——**全论文各问流程图统一这套取色**,不再用旧的三类灰度。
- 数据图/机理示意图若另用流程图,旧三类语义(输入=`dat` 淡蓝、处理=`box` 淡灰、结果=`res` 淡绿)仍可保留,箭头统一 `Stealth` 灰色;但**各问求解流程图一律走蛇形 6 色**。

## 6. 数据图长宽比

- 通用 `figsize`(dpi=150):横向条形 6.4-6.8 × 4.0-4.2;玫瑰图/极坐标 8.4 × 7.4;甘特图 8-9 × 4-5。
- 原则:**宽 > 高**(期刊排双栏友好),除非数据本身是纵向结构。高 > 宽的图放进版心很突兀。
- 多子图拼排时总宽 ≤ 9.5,子图比例一致。

## 7. CJK 豆腐块预警(必须当失败处理)

- 任何 `findfont` 或 `Glyph ... missing from font` 警告 = 中文渲染成空心方块,是**失败**,不是噪音——即使代码退出码为 0。
- 渲染时**不要**抑制字体警告(`warnings` 别吞),让它暴露问题。
- 修法:按 3.2 的 `font.family` 列表配方显式给 CJK 字体;LaTeX 里 xelatex + ctexart 自动处理。
- **你无法肉眼看图,警告是唯一信号:有警告就重渲,不要交付豆腐块图。**

### 7.1 成稿后的图片乱码复检(三道关,缺一不可)

图在生成时没警告,不等于印到 PDF 里就是好的——字体嵌入失败、TikZ 缺字、PNG 被二次压缩都会导致成稿乱码。交付前必须复检:

1. **渲染期警告**:matplotlib 的 `findfont` / `Glyph missing`;xelatex log 里的 `Missing character`。任何一条命中即失败。
   ```bash
   grep -n "Missing character" main.log        # 应为空
   ```
2. **PDF 文本层机检**:`python scripts/check_layout.py main.pdf` 的 `[4] 乱码/缺字` 段扫描全篇替换符(U+FFFD)与空心方块(U+25A1/25A0)。
3. **逐页转图片人眼/多模态核验**(唯一能发现"字变成方块但文本层正常"的手段):
   ```bash
   pdftoppm -png -r 120 -f 1 -l 30 main.pdf review/page
   ```
   逐张看图内文字、坐标轴标签、图例、TikZ 节点文字是否可读。**这是最后一道关,不能省**——文本层正常而字形缺失的情况,前两道关都查不出来。详见 `review.md` 的逐页视觉审查协议。

## 8. 图表密度、页面占比与子图拼排

- **一页最多两张图表为宜**。过多的可视化会割裂文本、段落、公式推导的联系。
- **单页图表视觉占位 ≤ 版心的 2/3**(硬性)。控制手段:`\includegraphics[width=0.85\textwidth]` 起步、满幅最多 `0.95\textwidth`,TikZ 用 `\resizebox{0.92\textwidth}{!}`;**禁止** `height=\textheight` 之类把图拉满页。
- **严禁图挨图**:两张图之间必须垫至少 40 字(约 2 行)对上一张图的解读,caption 不算正文。写不出 40 字解读的图,说明它没必要放——删掉或与前图合并为子图。
- 上述两条用 `python scripts/check_layout.py main.pdf --tex main.tex` 机检(脚本把位图、TikZ 矢量绘制、三线表表格线都算进图形带),详见 `writing.md` 第 6.3 节。
- 子图一行最多 3 个,超过 3 个换行。
- 子图一行排列时,**把图的字体单独调大**,免得看不清。
- 子图间距 0.2cm,子图内留白 0.1cm。
- **尽量少绘制**包含多个子图的图;但当同一指标有多张小图导致图挨图时,合并为子图是首选解法(合并后整体仍受 2/3 约束)。

## 9. 图片命名规范(必须详细可识别内容)

编程手生成的可视化图片,**文件名必须非常详细、能直接识别内容**。禁止用 `fig1.png`、`fig2.png` 这类无意义命名。

**命名格式**:
```
Q{题号}_{内容描述}_{图表类型}.png
```

**要求**:
1. 文件名让读者一眼看出:哪一问 + 画了什么 + 什么图。
2. 内容描述用中文,精炼但具体(4~10 字)。
3. 图表类型用标准名称(折线图/柱状图/条形图/箱线图/散点图/气泡图/热力图/甘特图/饼图/玫瑰图/漏斗图/桑基图等)。
4. 对比/多序列时,点名对比对象或变量。
5. 内容描述里写**核心变量名或结论对象**,不是"结果图""分析图"这种空话。

**命名示例**:

| 错误(不可用) | 正确(可用) |
|---|---|
| `fig1.png` | `Q1_各赛季观众数时序折线图.png` |
| `fig2.png` | `Q1_不同场馆观众分布箱线图.png` |
| `result.png` | `Q2_优化前后调度方案甘特图对比.png` |
| `图3.png` | `Q2_求解算法收敛过程折线图.png` |
| `plot4.png` | `Q3_各因素重要性排序横向条形图.png` |
| `fig5.png` | `Q3_预测值与真实值散点图.png` |

**与论文编号的映射**:文件名用于识别内容(给论文手挑图、评审查图),论文正文中仍用 `fig1..figN` 顺序编号 + 图题。论文手定图单时,`source` 填的是这个详细文件名;论文 `\includegraphics` 引用时按图单映射到 `figures/` 下对应文件。

## 10. 图表与正文呼应

- 每张图/表都要被正文 `\ref` 引用,并在正文里**解读出关键数字**(图里的最高值、阈值、对比结论),不能让图自说自话。
- **图表必须与首次引用同页或相邻页,且内容上紧随引用**。LaTeX 浮动体默认会漂移,一律用 `[H]` 固定 + 源码紧跟引用段落 + 章节前 `\FloatBarrier`,详见 `writing.md` 第 6.1 节。
- **图题/表题写 100–150 字长说明**(四段式:这是什么 → 怎么来的 → 关键数字 → 说明什么),不写光秃标题。表题在表上方,图题在图下方。详见 `writing.md` 第 6.2 节。
- 图题、表题风格统一("问题二: …"、"表4: …"),编号连续。统一体现在**开头句式**上,不是长度一致。
- **图内已有直接数值标注时,正文不必重复每个数**,只点最关键的。caption 已给的关键数字,正文只点最核心的一两个,避免图表重复描述。
