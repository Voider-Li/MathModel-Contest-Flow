# 阶段 3.5:独立数据挖掘(强制独立成章)

数据挖掘不是"预处理顺手做一下",而是论文里**独立成章**的一部分。评委看的是"你有没有真正读懂数据、数据里有什么规律、这些规律如何支撑你后面选模型"。本阶段的目标:在建模求解之前,把数据从"一堆附件"变成"有结论的证据",并让这些结论直接指向建模选择。

> **门禁等级:一致性级(缺失整章 → 红线级)。** 没有独立数据挖掘章的论文,在评审里属于"数据工作不完整",必须补齐。

## 1. 为什么必须独立成章

- **可复现性**:数据怎么来的、怎么洗的、有没有泄露,必须能被人一眼看穿,而不是散落在各问里。
- **支撑建模**:后面为什么选对数线性而不是神经网络、为什么用某组特征,答案应当来自本章的分布/相关/分组分析。
- **防泄露**:训练/验证/测试怎么划分、哪些特征"事后才可知",必须在本章交代清楚(见 `validation.md`)。
- **区分度**:同题论文模型往往相似,数据挖掘做得深是常见的拉分点。

## 2. 数据挖掘章必备七项(缺一不可)

论文独立章节(通常作为"数据预处理与数据挖掘"章)必须覆盖以下七块:

| # | 内容 | 要点 |
|---|---|---|
| 1 | **数据来源与字段字典** | 每个附件/表:来源、规模(行×列)、单位、字段含义、类型;缺失与非法值定义 |
| 2 | **缺失、重复、离群、非法值处理** | 每类的**判定标准**与**处理方式**(删除/插补/截断),以及**依据**;插补方法要写清(均值/中位数/回归/多重插补) |
| 3 | **单变量分布与目标分布** | 数值列直方图/密度图 + 关键统计量;类别列的频次;目标变量分布、类别不平衡程度 |
| 4 | **相关与共线性、分组差异** | 相关矩阵/热力图;VIF 或相关系数阈值排查共线;按关键分组(队/场馆/地区/时段)做差异检验 |
| 5 | **重复测量 / 时序轨迹** | 若存在个体重复测量或时序:个体轨迹图、变化模式、采样间隔是否均匀 |
| 6 | **特征工程与防泄漏** | 派生特征的业务含义、构造公式;明确哪些特征"预测时点已知",标注泄露风险特征 |
| 7 | **数据挖掘结论 → 建模选择的直接影响** | 明确写出"因为发现了 X,所以第 k 问选了 Y 模型" |

> 第 7 项最容易被忽略,却是本章的价值所在——数据挖掘不是摆设,它必须**改变或支撑**后续建模决策。

## 4. EDA 最小脚本骨架

```python
import pandas as pd, numpy as np, matplotlib.pyplot as plt
from pathlib import Path

DATA = Path(r"<绝对路径>/02_data")          # 必须绝对路径,禁止相对路径猜文件名
OUT  = Path(__file__).parent / "results"; OUT.mkdir(exist_ok=True)

df = pd.read_excel(DATA / "附件1.xlsx")      # 读真实文件,严禁 np.random 造数据

# 1) 结构体检
print(df.info()); print(df.describe().T)
print("缺失:\n", df.isnull().sum())
print("重复行:", df.duplicated().sum())

# 2) 分布
df.hist(figsize=(10, 6)); plt.tight_layout(); plt.savefig(OUT / "Q0_数值列分布直方图.png", dpi=150)

# 3) 相关与共线
corr = df.select_dtypes("number").corr()
plt.figure(figsize=(8, 6)); plt.imshow(corr, cmap="RdBu_r", vmin=-1, vmax=1)
plt.colorbar(); plt.savefig(OUT / "Q0_数值列相关矩阵热力图.png", dpi=150)
print("高相关对(|r|>0.8):\n", [(a, b, round(corr.loc[a, b], 3))
      for a in corr for b in corr if a < b and abs(corr.loc[a, b]) > 0.8])

# 4) 分组差异
print(df.groupby("场馆")["上座率"].agg(["mean", "std", "count"]))
```

## 5. 常见踩坑

| 坑 | 后果 | 规避 |
|---|---|---|
| 数据挖掘写成"预处理流水账" | 无结论、无支撑 | 每条处理都要有"发现 → 影响" |
| 缺失值一律填 0 / 均值 | 掩盖结构、引入偏差 | 先判断缺失机制(随机/系统),再选插补 |
| 对全数据做标准化 | 泄露 | 只用训练集 fit(见 `validation.md` 与 `review.md` §9) |
| 相关矩阵里 |r|>0.9 的特征全留 | 共线性毁掉回归系数 | 做 VIF / 逐步剔除,或改用正则 |
| 目标变量分布不查就建模 | 类别极不平衡时准确率虚高 | 先看目标分布,不平衡要报基线 |
| EDA 图无结论 | 只是"好看的图" | 每张图配 100–150 字解读(见 `writing.md` §6.2) |
