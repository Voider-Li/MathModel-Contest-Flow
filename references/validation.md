# 阶段 5.5:独立检验与模型检验章(强制独立成章)

模型能不能用,不由训练集上的漂亮指标决定,而由**从未参与训练的独立数据**决定。本文件规定论文"模型检验与评价"章的强制内容,以及"独立测试集门""基线对比门""数值冻结门"三条硬门禁。

> **门禁等级:独立测试集门 = 红线级。** 分类/预测/回归类题目,最终指标必须来自独立测试集;交叉验证只能补充,不能替代。

## 1. 三条硬门禁

### 1.1 独立测试集门(红线级)

- 必须按**独立单元**划分训练/验证/测试——单元可以是:个体、场馆、批次、时空单元、时间段。**不能**简单随机打乱样本行(会把同一单元的信息漏进测试集)。
- 最终报告的主指标**只能**来自从未参与训练与调参的测试集。
- 若数据量过小、无法留出测试集,必须显式说明,并改用**嵌套交叉验证**或**时间外推**(用最后一段做测试),同时如实标注"非独立测试集"。
- 时序问题:**只能**用过去预测未来,禁止随机划分。

### 1.2 基线对比门(一致性级)

- 每个 Qx 结尾必须有一张"**基线 vs 主方法 vs 备选**"对比表(模板见 §3)。
- 基线必须"能完成真实任务、产出可比指标",**禁止用玩具方法冒充基线**(如把随机猜测当基线)。
- 分类题必须含**多数类基线**;回归题必须含**简单基准**(如均值/上一期值/线性模型);优化题必须含**风险/成本/误差或收益差异**。
- 论文里禁止用"明显提升""最优"代替对比表和统计检验。

### 1.3 数值冻结门(红线级)

- 所有正文数字必须来自**已冻结的结果文件**(`results/` 下的 CSV 或 `reports/RESULTS_REPORT.md`)。
- 冻结时点:独立测试集指标、对比表、稳健性/敏感性结果全部跑完之后,才允许开始写论文。
- 论文写作期间**禁止**新增、改写或口头补充数值;若必须改,回到代码重跑、重新冻结、同步更新摘要/正文/表格/README(见 `review.md` §5.2)。

## 2. 模型检验章必备清单(缺一不可)

论文"模型检验与评价"章(独立成章,通常第 6 章)必须覆盖:

| # | 内容 | 要点 |
|---|---|---|
| 1 | **数据划分协议** | 按什么独立单元划分、比例多少、为何这样划分;分类任务是否分层 |
| 2 | **训练/验证/测试集规模** | 三者的样本数(与单元数),划分是否泄漏 |
| 3 | **测试集最终指标** | 主指标 + 置信区间/误差范围;**明确标注"测试集"** |
| 4 | **交叉验证与测试集对照** | 训练集 K 折 CV 指标 vs 测试集指标,差异大要解释 |
| 5 | **阈值/参数/误差敏感性** | 关键阈值、超参、噪声/误差扰动 ±10%~50% 下结论是否翻转 |
| 6 | **失败样本分析** | 漏报/误报/异常结果的具体案例与原因,不是一句"个别样本" |
| 7 | **泛化性与局限性** | 结论能推广到哪、不能推广到哪、数据/假设的边界 |

> 与 `modeling.md` §4 的关系:那里的"残差诊断三件套、稳健性对照、敏感性分析"是**建模阶段**的验证动作;本章是把这些动作的**结果汇总成章**,并补上独立测试集与失败样本分析。

## 3. 对比表模板(每问至少一张)

| 方案 | 指标1 | 指标2 | 相对基线差异 | 结论/选择 |
|---|---|---|---|---|
| 基线(多数类/均值/现状) | ... | ... | — | 作为参照 |
| 主方法 | ... | ... | +x% / -y | 采纳,原因… |
| 备选 | ... | ... | ... | 未采纳,原因… |

- 对比图放**同一坐标系**;坐标轴、单位、图例完整。
- 分类题补 ROC/PR 曲线或混淆矩阵;回归题补残差图;优化题补方案差异条形图。
- "提升多少"必须给数值,不给"显著提升"这类空话。

## 4. 数据泄露自查(红线级,逐条过)

- [ ] 时序/按时间展开的数据,训练只用过去;预测某样本只用它**发生之前**可得的变量
- [ ] 未来信息特征已排查:每个特征"预测时点是否已知"(如"是否淘汰赛"已知 OK;"该场实际比分/实际观众"事后才知 = 泄露)
- [ ] 标准化/归一化只对**训练集** fit,测试与预测用训练集参数 transform
- [ ] 全局统计量(缺失填充值、全局均值/极值、词表)未从含测试的全数据算出
- [ ] CV/OOB 使用如实标注"基于训练集 CV",不冒充测试集精度
- [ ] 外部数据(真实赛程/官方口径)只作评估对比,不参与训练,边界写清

## 5. 可复现的检验脚本骨架

```python
import numpy as np, pandas as pd
from sklearn.model_selection import GroupShuffleSplit, cross_val_score
from sklearn.metrics import mean_absolute_error, r2_score

# 按独立单元(如场馆)划分,杜绝同单元泄漏
gss = GroupShuffleSplit(n_splits=1, test_size=0.2, random_state=42)
tr, te = next(gss.split(X, y, groups=df["场馆"]))

model.fit(X.iloc[tr], y.iloc[tr])
pred = model.predict(X.iloc[te])            # 测试集预测
test_mae = mean_absolute_error(y.iloc[te], pred)
test_r2  = r2_score(y.iloc[te], pred)

cv = cross_val_score(model, X.iloc[tr], y.iloc[tr], cv=5, scoring="neg_mean_absolute_error")
print(f"[冻结] 测试集 MAE={test_mae:.4f}  R2={test_r2:.4f}  | 训练集5折CV MAE={-cv.mean():.4f}")

# 冻结:把测试集指标写入结果文件,后续论文只引用这里的数字
pd.DataFrame([{"split": "test", "MAE": test_mae, "R2": test_r2,
               "cv_MAE": -cv.mean()}]).to_csv("results/frozen_metrics.csv", index=False)
```
