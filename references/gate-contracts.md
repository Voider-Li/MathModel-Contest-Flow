# 门禁产出契约

## G1 问题框架

每个 Qx 在 `planning/framing/Qx.md` 记录：

- 目标输出（数值、方案、方法或策略）
- 对象与独立单元（个体、批次、时空单元等）
- 数据字段到输出的映射
- 评价口径与成功标准
- 关键风险（缺失、不平衡、泄漏、样本量不足）

## G2 方法卡

每个 Qx 在 `methods/Qx/qx_method_card.md` 记录：

- Goal and success criteria
- `main_candidate` / `usable_baseline` / `conditional_fallback`
- Baseline validity（真实任务、可比输出）
- 风险探测摘要
- fallback trigger
- human decision id（来自 `qx_decisions.jsonl`）

## G3 数据挖掘章清单

论文独立章节必须出现：

1. 数据来源、规模、字段字典
2. 缺失、重复、离群、非法值处理及依据
3. 单变量分布、目标分布、类别不平衡
4. 相关矩阵与共线性；分组差异检验
5. 若存在重复测量或时序：个体轨迹、变化模式、采样间隔
6. 特征工程：派生特征、业务意义、防泄漏说明
7. 数据挖掘结论对建模选择的直接影响

## G6 模型检验章清单

- 数据划分协议（按独立单元，分类任务做分层划分）
- 训练/验证/测试集规模与比例
- 测试集最终指标（不得由交叉验证替代）
- 交叉验证与测试集指标对照
- 阈值、参数、误差敏感性
- 失败样本分析（漏报、误报或异常结果）
- 泛化性与局限性

## G5.5 文献管理

- 写作前建立 `references/` 文献库，格式使用 `.bib` 或 `references.json`。
- 每条文献必须包含：作者、标题、年份、期刊/会议/教材/标准、卷期页码、DOI 或 URL、来源文件或检索链接、`verified` 标记。
- 来源只允许真实检索到的文献；找不到原文的条目标记 `unverified`，不得进入正文。
- 正文使用 `\cite{key}` 或 `@cite(key)`，禁止手写“文献[5]”。
- 交稿前逐条核验：key 是否存在、是否被正文引用、作者/年份/期刊是否正确、正文表述是否与文献结论相符。
- 中文文献优先用知网/万方/维普，英文文献优先用 Crossref/Google Scholar/Semantic Scholar，见 `references/reference-sources.md`。

## 其他硬门禁

### 数值冻结

- 论文只从冻结结果取数；冻结前完成独立测试集指标、对比表和稳健性结果。
- 每个关键数字必须能指到 `results/` 或 `reports/RESULTS_REPORT.md` 中的来源。

### 代码可复现

- 固定随机种子、依赖版本、数据路径；运行入口明确。
- 提交前完整运行一遍；评审时检查泄漏、样本划分、除零、边界情况和“只为了跑通”的假逻辑。

### 图表纪律

- 每张图必须被正文引用；未引用图删除。
- 对比图放同一坐标系；坐标轴、单位、图例完整。
- 图表标题与实际内容一致，禁止“三子图却只写一个染色体”这类错位。

### 表达规范

- 低拟合、低性能直说原因，不包装成“效果良好”。
- “最优、明显、显著”必须有对比表或统计检验支撑。
- 符号、单位、变量名全篇一致；符号表覆盖正文所有符号。

### 流程分工

- 同一文件同一时间只允许一个 Agent 写入。
- 阶段产物固定命名：`ANALYSIS_MODELING_REPORT`、`DATA_MINING_REPORT`、`RESULTS_REPORT`、`COMPARISON_REPORT`、`VERIFY_REPORT`。
- 72 小时赛程建议时间点：24h 方法冻结、48h 数值冻结、最后一天只做论文、编译和验收。

### Agent 通用约束

- 禁止编数据、编文献、编实验结果。
- 失败或不确定必须明说，不假装成功。
- 人工决策点必须停下问人，不替用户拍板。
- 每个结论都能指到具体产物文件。

## 论文硬检查

- 自动编号与交叉引用，无“图8”式硬编码
- 每张图都被正文引用，未引用图删除
- 每个数值可溯源到结果文件或代码输出
- 每处“最优、明显、显著”都对应对比表或检验
- 优先使用用户提供的模板（当前工作区约定为 `全国大学生数学建模竞赛LaTeX模板/`），保留 `.cls`、封面与排版样式
- 使用 `xelatex` 编译并跑两遍，提交前确认 PDF 可正常生成
- 最终提交前运行 `6verity` 与 `quality-assurance-auditor`
